Optimal Power Flow (OPF)

VFlexP solves the AC, DC, and hybrid AC/DC Optimal Power Flow via the MATPOWER-FUBM universal branch formulation, available interactively from the Run OPF button in the Static Analysis tab or programmatically via vflexp_run_opf(session).

1. Objective Function & Cost Data

The OPF minimises total generation cost \(\min \sum_i C_i(P_{g,i})\) defined in the optional Gen cost data sheet (polynomial or piecewise-linear MATPOWER cost rows). When a case workbook omits Gen cost data, VFlexP supplies a default quadratic cost curve so constrained dispatch optimisation can still be run out of the box.

2. Network & Converter Constraints

  • Bus voltage bounds: enforces \(V_{\min} \le V_m \le V_{\max}\) across all AC and DC buses.
  • Generator capability: enforces active and reactive capability bounds (\(P_{\min} \le P_g \le P_{\max}\), \(Q_{\min} \le Q_g \le Q_{\max}\)).
  • Branch thermal & angle limits: enforces apparent power ratings (rateA) and angle difference bounds (angmin, angmax).
  • VSC interface converters: co-optimises AC/DC converter active and reactive power transfers, voltage setpoints, equivalent susceptance (BEQ), and quadratic converter losses (ALPHA1..ALPHA3).

Upon convergence, vflexp_run_opf updates the session dispatch tables (Bus, Gen, IntConv) and refreshes the System Diagram, ready for immediate dynamic unit initialisation, time-domain simulation, or small-signal modal analysis.
