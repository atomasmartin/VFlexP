Grid-Following Converter (GFL & intconv_GFL)

The name Current Controlled Voltage Source Inverter (CCVSI) is introduced in [1] for grid-following converters, a type of DC/AC converter that measures the voltage angle at its point of connection using a phase-locked loop (PLL) and injects the active and reactive power required by controlling the output current. In VFlexP, it is available both as an AC generator (GFL) and as an AC/DC interface converter (intconv_GFL).

The abc/dq blocks represent the power-invariant Park's transform to a rotating \(dq0\) frame, in which the active and reactive power are: $$ P = v_{odi}i_{odi} + v_{oqi}i_{oqi} \hspace{2cm} Q = v_{oqi}i_{odi} - v_{odi}i_{oqi} $$

Level 0 and Synchronization Control

Phase-Locked Loop (PLL_complexity)

  • dynamic: PI controller (Kp_pll, Ki_pll) driving $v_{oq}^{\text{local}} \to 0$ to track the terminal bus angle.
  • static: Instantaneous algebraic angle tracking $\theta_{\text{pll}} = \mathrm{atan2}(v_q, v_d)$.

Current Controller (CC_Complexity)

Dynamic current controller (dynamic)

Static current controller (static)

If the inner current controller dynamics are not relevant, they can be eliminated so the converter tracks its current reference instantaneously: \begin{equation} i_{l d i}^{*}=i_{l d i} \hspace{2cm} i_{l q i}^{*}=i_{l q i} \end{equation}

Power & DC-Voltage Controller (PC)

The power controller computes the $dq$ current references from the filtered active and reactive power references (time constant $T_a = 1/\text{iTf}$), primary frequency droop $1/R_p$, and reactive voltage droop $K_q$:

\begin{equation} i_{ldi}^* = \frac{v_{odi} P^{\text{ref}}_i + v_{oqi} Q^{\text{ref}}_i}{v_{odi}^2 + v_{oqi}^2}, \hspace{1.5cm} i_{lqi}^* = \frac{v_{oqi} P^{\text{ref}}_i - v_{odi} Q^{\text{ref}}_i}{v_{odi}^2 + v_{oqi}^2} \end{equation}

In intconv_GFL, an outer DC-voltage PI/droop controller (K_p, K_i, set via Kpvdc and Kivdc in .dyr) adds $\Delta P_{\text{dc}} = (K_p + K_i/s)(v_{\text{dc,ref}} - v_{\text{dc}})$ to the active power reference, coupling the AC power injection to the DC grid voltage and FUBM converter loss model ($\alpha_1, \alpha_2, \alpha_3$).
