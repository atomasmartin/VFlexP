Modal Analysis, State Relevance & Parametric Sweeps

VFlexP provides analytical Simulink linearisation, small-signal modal analysis, balanced-realisation state relevance, automatic complexity reduction, and parametric sweeps through dedicated tabs in the VFlexP App (Modal Analysis, State Relevance, and Complexity) as well as headless MATLAB functions in core/.

1. Single Linearisation & Eigenvalue Analysis (Modal Analysis Tab)

vflexp_linearise(session) and vflexp_modal(session) linearise Simulink/VFlexP.slx analytically around its initialised operating point (\(\dot{x} = \mathbf{A}x + \mathbf{B}u,\; y = \mathbf{C}x + \mathbf{D}u\)), map every Simulink integrator state back to its physical bus, branch, or generating unit (vflexp_map_state_names), and compute:

  • Eigenvalues, natural frequencies & damping ratios: visualised in both Damping (%) vs Frequency (Hz) and Complex S-Plane views.
  • Normalised participation factors: \(P_{ki} = |V_{ki} W_{ik}| / \sum_j |V_{ji} W_{ij}|\), displayed interactively as bar charts and sortable tables for any selected mode, with one-click export to .xlsx or .mat.

2. State Relevance & Automatic Complexity Reduction (State Relevance Tab)

The state relevance coefficient measures the importance of each physical state in the system's input-output response over user-selected disturbance inputs and observed outputs. Based on the balanced realisation (\(\texttt{balreal}\)) and modal participation factors of the original and balanced systems (A. Tomás-Martín et al., "State relevance for modal analysis and model reduction in power systems," IJEPES, 2023), vflexp_relevance(session) computes a normalised relevance vector (scaled to a maximum of 1).

Selecting a relevance threshold and clicking Set complexity (or calling vflexp_apply_relevance(session, threshold)) automatically simplifies sub-blocks whose states all lie below the threshold (for example, order 8 → order 4 synchronous machine stators, dynamic → static converter inner loops, or dynamic RL branches to quasi-stationary static omega models) while preventing algebraic loops.

3. Dynamic vs Static Parametric Sweeps

Both the Modal Analysis and State Relevance tabs include two parametric sweep sub-tabs backed by vflexp_sweep:

  • Sweep: dynamic model (mode = 'keep'): sweeps control parameters or symbolic $name variables that do not alter the steady-state power flow, keeping the power-flow solution fixed for fast root-locus and state-relevance sensitivity studies on larger grids.
  • Sweep: static model (mode = 'recompute'): re-solves the MATPOWER-FUBM power flow and re-initialises all dynamic units at every parameter step (suitable when sweeping generation dispatch, load scaling, or network impedances that shift the steady-state equilibrium).
