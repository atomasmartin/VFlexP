Dynamic Unit Initialisation & Time-Domain Simulation

1. Steady-State Equilibrium Computation (vflexp_build_and_init)

Starting from the solved hybrid AC/DC power flow, vflexp_build_and_init(session) computes the exact steady-state initial conditions (\(\dot{x} = 0\)) of every active network element, generator, converter, and controller:

  • Analytical initialisation: AC/DC bus capacitors, inductive transmission lines, RL/constant-power loads, grid-forming converters (VSM, GFM, intconv_VSM, intconv_GFM), grid-following converters (GFL, intconv_GFL), and DC sources (DC_PES) are initialised in closed form from terminal phasors \((V_m, \theta)\) and complex power injections \((P, Q)\).
  • Isolated single-unit findop refinement: Detailed rotating machines and controls (such as MGES with ST4B, IEEEG1, and PSS2B) combine analytical flux-linkage and rotor-angle expressions with an isolated temporary model trim when needed, guaranteeing machine-precision equilibrium.

2. Modular Simulink Libraries Without Breaking Links

All device and network blocks in Simulink/VFlexP.slx are resolved library links (LinkStatus = 'resolved') pointing to standalone libraries in Simulink/lib/. Instead of mutating internal Simulink integrators or commenting blocks out, vflexp_build_and_init writes parameter structures (prm_*) and initial-state structures (op_*) exclusively into the ModelWorkspace. Complexity variants switch via Simulink expression-mode Variant Subsystems, keeping VFlexP.slx and every library clean in Git (Dirty = 'off').

3. Time-Domain Simulation & Disturbance Events (Simulation Tab)

In the Simulation tab (or via vflexp_simulate(session)), you can configure temporal disturbance events in session.eventList—including step or rectangular-pulse changes in AC/DC bus loads, generator/converter power or voltage references, and AC transmission line closing at \(t = t_{\text{ev}}\)—run Simulink via Simulink.SimulationInput, and inspect multi-channel trajectories in interactive scopes.
