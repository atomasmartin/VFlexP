Virtual Synchronous Machine (VSM & intconv_VSM)

The Virtual Synchronous Machine (VSM) is a grid-forming converter control structure that sets the voltage magnitude and angle at its point of connection while emulating synchronous machine inertia and damping. In VFlexP, it is available both as an AC generator (VSM) and as an AC/DC interface converter (intconv_VSM).

The abc/dq blocks represent the power-invariant Park's transform to a rotating \(dq0\) frame, where active and reactive power are: $$ P = v_{odi}i_{odi} + v_{oqi}i_{oqi} \hspace{2cm} Q = v_{oqi}i_{odi} - v_{odi}i_{oqi} $$

Level 0 control

In general, the inner voltage and current controllers of an electronic converter are included in Level 0 control. This is the fastest control layer, responsible for tracking inner voltage and current references and limiting converter current during faults.

Voltage and Current Controller (VCC)

In both VSM and intconv_VSM, the complexity of the inner voltage and current controller (VCC_Complexity) can be chosen between:
  • dynamic: Full cascaded PI voltage controller (kp_v, ki_v) and PI current controller (kp_i, ki_i) with dynamic $LC$ filter (Rf, Lf, Cf).
  • static: Algebraic inner voltage/current loop ($v_{idi}^* = v_{odi},\; v_{iqi}^* = v_{oqi}$).
  • dynamic_limiting (or dynamic_limiting_P / dynamic_limiting_DC in intconv_VSM): Dynamic cascaded control with current reference saturation.

If the voltage and current controller dynamics are not relevant, they can be eliminated: \begin{equation} v_{i d i}^{*}=v_{o d i} \hspace{2cm} v_{i q i}^{*}=v_{o q i} \end{equation}

Primary control

Power Controller

The power controller of a VSM emulates the swing equation with virtual inertia time constant \(T_a = 2H\), frequency droop \(k_{\text{droop},f} = 1/R_p\), and damping \(D\): $$ T_a \frac{\mathrm{d}\omega}{\mathrm{d}t} = P_{\text{ref}} - P_{\text{meas}} - (k_{\text{droop},f} + D)\cdot(\omega-\omega_{\text{ref}}) $$ A reactive-power voltage droop sets the voltage magnitude reference: $$ v_{\text{ref}} = v_{\text{ref}0} + k_{\text{droop},u} \cdot (Q_{\text{ref}} - Q_{\text{meas}}) $$

AC/DC Interface Converter (intconv_VSM) and DC-Voltage / ATM Control

When used as an AC/DC interface converter (intconv_VSM), the converter exchanges active power $P_{\text{ac}} = v_{id}i_{id} + v_{iq}i_{iq}$ plus FUBM converter losses ($\alpha_1 + \alpha_2 |i_c| + \alpha_3 |i_c|^2$) with the DC bus ($i_{\text{dc}} = (P_{\text{ac}} + P_{\text{loss}})/v_{\text{dc}}$).

In addition, intconv_VSM includes a selectable active-power reference control variant (Ref_control_complexity):

  • Constant: Constant active-power reference $P_{\text{ref}} = P_0$.
  • DC_ATM: DC-voltage droop (K_p_dc, filtered by T_f_dc) combined with an Active-power Tracking Mode (ATM) PI regulator (k_p_atm, k_i_atm, bounded by [-P_atm_lim, P_atm_lim]) that coordinates DC bus voltage regulation and fast active-power tracking.
